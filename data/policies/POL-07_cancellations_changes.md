# POL-07: Cancellations and Order Changes

**Document ID:** POL-07 | **Version:** 1.0 | **Effective date:** 2026-01-01 | **Owner:** Brightcart Customer Care

## Purpose

This policy explains when a customer can cancel an order or change its delivery address.

## The rule: before shipment only

Brightcart allows a customer to **cancel an order or change its delivery address only before the order ships**. An order whose status is *processing* can be cancelled or changed. Once the status is *shipped*, *in transit* or *delivered*, the order can no longer be cancelled or redirected, because the package is already with the carrier.

## Cancelling an order that has not shipped

If the order is still processing, the agent can recommend cancellation. The full amount, including shipping, is refunded to the original payment method. Customers should expect the refund 5 to 7 business days after the cancellation is confirmed.

## Changing the address

If the order is still processing, the agent can recommend an address update. The customer must provide the complete new address. Support does not store it in free-text notes; it goes into the order system by the fulfilment team. In this tool the agent only records the recommendation.

## Orders that have already shipped

After shipment, **cancellation is refused**. The agent explains that the package has already left our warehouse and offers the alternative: the customer can **return the item after delivery** under the normal return rules in POL-01. The customer should not refuse delivery or ask the carrier to return the parcel, because this causes delays and extra fees.

## Orders already cancelled

If an order was cancelled and the refund has been issued, the customer is told the date of the refund and the 5 to 7 business day timeline. If more than 7 business days have passed without the money arriving, the agent escalates.

## Edge cases

If the status is unclear or the customer disputes the shipment date, the agent escalates rather than guessing. Cancellation requests never need manager approval, because the refund is the full amount paid for an order that has not shipped.

## What to tell the customer

Be clear and brief. State whether the request is possible, and give the next step.
