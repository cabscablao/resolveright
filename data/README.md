# Data

**All data in this folder is synthetic.** There are no real people, companies, emails (all use `@example.test`), addresses or payment data. "Brightcart" is a fictional store.

- `policies/*.md`: 10 policy documents (POL-01 to POL-10), the source of truth for rules.
- `customers.json`, `orders.json`: generated by `scripts/generate_data.py` (seeded, reproducible). Dates are relative to `AS_OF_DATE` (2026-11-02), so day counts never drift.

Regenerate: `uv run python -m scripts.generate_data`. Verify: `uv run python -m scripts.seed_checks`.

Extra order fields beyond the master prompt: `refund_date` (when a refund was issued) and `current_price` on an item (set only for the price-adjustment order ORD-1020).
